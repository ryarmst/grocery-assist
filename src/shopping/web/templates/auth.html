Searching and deals work without a connection. Reading or changing the cart needs a logged-in session. No Frills blocks automated logins, so you paste the session token from your own browser. It lasts about an hour.

Paste a session token

  1. Log in at nofrills.ca (reload the page if it's been open a while — that refreshes the token).
  2. Open DevTools → Application (Firefox: Storage) → Cookies → https://www.nofrills.ca.
  3. Copy the value of the AccessToken cookie (starts with eyJ) and paste it below.
